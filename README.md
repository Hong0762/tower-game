# 守塔军师 · 策略塔防

手机网页塔防小游戏：零安装、手机浏览器直接玩、触屏操作。

## 玩法

- 点击空地建塔（**按住卡片预览射程圈**），点击已建塔升级/拆除
- **六种塔**（后面三个每 10 波解锁一个，含克制加成）：
  - 箭塔（弓箭·速射单体·**克重甲 +25%**）
  - 炮塔（大炮·溅射群伤）
  - 冰塔（雪花·减速控场）
  - 雷塔（特斯拉线圈·闪电连锁跳跃·**克飞行 +40%**，第 10 波解锁）
  - 毒塔（毒罐·剧毒持续伤害·**克 Boss +30%**，第 20 波解锁）
  - 激光塔（晶体·高温光线直线穿透·**克飞行 +50%/克重甲 +25%**，第 30 波解锁）
- 塔每升一级外观逐级更华丽，Lv3 金装、Lv4 白金框、Lv5 顶部白星
- **塔 5 级封顶**：开场三塔第 10/20 波后可升 Lv4/Lv5；后期解锁的塔相应顺延
- **每坚守 10 波：解锁新兵种 + 全军伤害 +5%**
- 右上角「榜」按钮随时查看排行榜（自动暂停，返回继续）；「速」按钮 2 倍加速（塔射速同步加快）
- 右下「❄冰冻」大招：全体敌人冻结 3 秒（45 秒冷却）
- 底部条实时预告**下一波构成**，便于提前布防
- 敌军沿蛇形谷道进攻军营，守住一波波强敌，波次无限
- 开局 200 金币、首波仅 7 只史莱姆（新手友好）；HUD 实时显示击杀数

## 怪物图鉴（按功能六类）

- **高速杂兵**：史莱姆、小甲虫、小蝙蝠（血少跑得快）
- **重甲慢速**：寄居蟹、石头小精灵、厚壳甲虫（血厚走得慢）
- **飞行怪**：幽灵、小飞虫、三角无人机（**不走谷道，直线扑营**）
- **刺客**：小蝎子、小蛇（极快，漏进营伤害翻倍）
- **精英**：水晶怪、萨满小地精（15 波起登场，萨满会给友军回血，优先击杀）
- **Boss**：每 10 波登场，为小怪同源放大 2 倍（巨型史莱姆/巨型寄居蟹/巨型幽灵/巨型水晶怪），20 波起成双、40 波起三连

- 敌军难度递进：血量成长 ×1.22/波、提速上限 +45%
- **每 10 波自动记录排名**（个人榜 + 34 省级行政区省份榜，如"广东省第1名"）
- 战斗每 3 秒自动存档，可"继续上次进度"续玩

## 在线游玩（两种方式）

1. **自托管完整版**（联机排行榜）：本机运行 Python 服务，手机经隧道访问
   ```
   python server.py        # 默认端口 18081
   ```
2. **GitHub Pages 静态版**：本机榜 + 读取 `scores.json` 共享榜合并显示（共享榜由主地址自动同步）

## 技术说明

- 单文件 HTML5 Canvas 游戏（`static/index.html`），无外部依赖、无第三方脚本
- 背景音乐由 Web Audio 实时合成（146 BPM 小调，无音频文件）
- 排行榜接口：`/api/scores`（GET 查询）、`/api/score`（POST 提交，同昵称保留最高分）
- 数据保存在运行端本地，不上传任何第三方
